# Manufacture Engine Core Library
The Core library of Manufacture Engine that provides essentials for any projects
- Basic types like 2D & 3D Vectors and ASCII Image
- Basic components like `Transform2D`, `Transform3D` and `CMDSprite`
- Data about Terminal input
- CMD Renderer with OpenGL-like Render Command scheduling

Paste `use manufacture_core::prelude::*` in your projects to start creating
